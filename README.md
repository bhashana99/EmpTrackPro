## Overview
EmpTrack Pro is a **full-stack CRUD application** built with **Angular 20** and **.NET 9 Web API** for managing employee records efficiently. The backend follows a **layered architecture** (Controller → Service → Repository) with **SQL Server Stored Procedures** for secure and optimized database operations. The frontend uses **Angular Signals** and **Reactive Forms** for reactive UI updates, edit-mode handling, and validation.

---

## Features
- Full CRUD operations for employee management  
- Layered backend architecture (Controller → Service → Repository)  
- SQL Server integration with Stored Procedures  
- Fully documented APIs via Swagger UI  
- Angular Signals for reactive state management  
- Modular UI with separate form and table components  
- Form validation with required fields and proper error messages  
- Responsive design for desktop and mobile  

---

## Tech Stack
- **Backend:** .NET 9 Web API, C#  
- **Frontend:** Angular 20, TypeScript, Reactive Forms, Angular Signals  
- **Database:** SQL Server + Stored Procedures  
- **Styling:** Tailwind CSS  
- **Tools:** Visual Studio 2022, VS Code, Git & GitHub

## Getting Started

### Clone the Repository
```bash
git clone https://github.com/bhashana99/EmpTrackPro
cd EmpTrackPro
```
### Prerequisites
 - Node.js >= 22
 - Angular CLI 20+
 - .NET 9 SDK
 - SQL Server (local or remote)

### Install Dependencies
```bash
npm install
```
